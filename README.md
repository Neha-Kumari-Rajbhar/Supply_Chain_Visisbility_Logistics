# 📦 Supply Chain Visibility & Logistics

An end-to-end data analytics project that transforms raw supply chain data into meaningful business insights using **Python** for data preprocessing and **Power BI** for interactive dashboard development.



## 📖 Project Overview

Supply Chain Visibility refers to the ability to monitor and analyze every stage of the logistics process, from order placement to final delivery. This project focuses on cleaning raw supply chain data, performing exploratory data analysis (EDA), and building an interactive Power BI dashboard to monitor delivery performance, warehouse operations, shipping methods, and transportation costs.

The project demonstrates a complete analytics workflow from **raw dataset → preprocessing → dashboard → business insights**.



## 🎯 Project Objectives

- Clean and preprocess the raw supply chain dataset.
- Handle missing values and duplicate records.
- Standardize data formats and data types.
- Perform Exploratory Data Analysis (EDA).
- Develop Key Performance Indicators (KPIs).
- Build an interactive Power BI dashboard.
- Generate business insights for better decision-making.

## 📈 Exploratory Data Analysis

EDA was performed to understand business trends before dashboard development.

Key observations include:

- Delayed orders represent the largest share of deliveries.
- Sea shipping is the most frequently used shipping mode.
- WH-Pune processes the highest number of orders.
- FastTrack Distributors handles the highest number of deliveries.
- Order value and transportation cost fluctuate over time.



## 📌 Key Performance Indicators (KPIs)

The dashboard tracks:

- Total Orders
- Total Order Value
- Total Transportation Cost
- Average Delay Days
- On-Time Delivery Percentage

## 💡 Business Insights

- Most deliveries are delayed, indicating opportunities to improve delivery performance.
- Sea transportation handles the highest number of shipments.
- Some warehouses process significantly more orders than others.
- Transportation cost contributes considerably to logistics expenses.
- On-time delivery performance requires improvement.
